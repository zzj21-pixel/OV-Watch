# OV-Watch
> 基于开源OV-Watch工程二次开发的智能手表项目，用于嵌入式技术学习与工程实践。
> 遵循原项目开源协议，保留原始版权声明。

## 项目简介
OV-Watch 智能手表工程，主控为STM32F411，搭载KT6328蓝牙芯片、ST7789显示屏。
我基于现有开源工程完成源码导入、仓库版本管理、工程编译调试，后续计划在原有BSP基础上新增自定义功能，熟悉嵌入式底层驱动、IAP固件升级、硬件原理图阅读。

## 硬件信息
- 主控芯片：STM32F411
- 蓝牙芯片：KT6328
- 屏幕驱动：ST7789
- 外设：独立按键、电源管理模块
- 硬件资料：原理图PDF、Gerber生产文件，存放于`Hardware`文件夹

## 软件目录结构
Software
├─ IAP_F411        # IAP 在线升级工程（支持固件蓝牙升级）
└─ BSP             # 底层驱动包
├─ KEY          # 按键驱动
├─ KT6328       # KT6328 蓝牙通信驱动
├─ LCD          # ST7789 屏幕显示驱动
└─ POWER        # 电源管理驱动

## 编译环境
- IDE：Keil MDK
- 芯片支持包：STM32F4系列
- 下载工具：ST-Link
